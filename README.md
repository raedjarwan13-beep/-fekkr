# فَكَّر — دليل النشر على Render

## محتوى المجلد
```
render-deploy/
├── package.json          # تعريف المشروع وأمر التشغيل (بدون حزم خارجية)
├── server.js             # خادم Node بسيط يخدم الواجهة
├── render.yaml           # إعدادات النشر التلقائي على Render (Blueprint)
├── .gitignore            # يستبعد المفتاح والكتب الضخمة والنسخ الاحتياطية
└── public/
    ├── index.html        # الواجهة الكاملة (التطبيق)
    ├── sw.js             # عامل الخدمة للعمل بدون اتصال
    └── books/txt/        # نصوص الكتب المستخرجة (4MB) + manifest.json
```

## ملاحظات مهمة
- **لا قاعدة بيانات**: بيانات الطالب تُحفظ في متصفحه (localStorage / IndexedDB) — تصميم مقصود للخصوصية.
- **ملفات PDF غير مرفوعة**: 438MB لا تناسب الاستضافة المجانية؛ الامتحانات والمعلم AI يشتغلان من نصوص الكتب المرفوعة (4MB).
- **مفتاح Gemini مضمّن في index.html**: أي شخص يفتح صفحة المصدر يراه. THIS مقبول من المطوّر، لكنه خطر أمني — يُنصح بتقييده من Google AI Studio أو نقله لخادم لاحقًا.

## النشر — خطوات يدوية
### 1) GitHub
1. أنشئ حسابًا على github.com إن لم يكن لديك.
2. New repository → الاسم مثلاً `fekkr` → Public → Create.
3. ارفع محتوى مجلد `render-deploy` كاملًا إلى جذر المستودع (اسحب الملفات أو استخدم Git).

### 2) Render
1. سجّل الدخول إلى render.com باستخدام حساب GitHub.
2. New → **Blueprint** → اختر مستودع `fekkr` → سيقرأ `render.yaml` تلقائيًا.
3. أو يدويًا: New → **Web Service** → اربط المستودع:
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Plan: `Free`
4. اضغط Create Web Service وانتظر حتى يصبح الحالة `Live`.
5. انسخ الرابط الذي يظهر (`https://fekkr.onrender.com`) وشاركه.

### 3) تحقق
- افتح الرابط على هاتفك.
- جرّب: مكتبة الكتب ← مولّد الامتحانات ← اقرأ جدول المحتويات ← ولّد الامتحان.
- تذكير: الخطة المجانية على Render تُوقف الخدمة بعد مدة عدم استخدام وتستغرق ثوانٍ للعودة — مقبول للعرض، لكن الرابط قد ينام بين الزيارات.
